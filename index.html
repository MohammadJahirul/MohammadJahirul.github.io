PDF Boss

v1.3 · iPhone & iPad · Productivity

Scan, sign, edit, convert and send PDFs and Word files. Every file stays on the device.

  • Redaction that really removes things. Marked areas are burned into pixels and each page is rebuilt as an image-only copy. The original is kept separately.
  • Scans become searchable. Vision OCR adds an invisible text layer, and the same text powers PDF-to-Word conversion.
  • No account, no backend. App Store privacy label: “Data Not Collected”.

Expense Packet

Receipts to reimbursement

A pile of receipts becomes one numbered PDF packet and a matching CSV.

  • Uncertainty is visible. Vision OCR feeds a parser that flags low-confidence fields for review.
  • Currencies stay separate. No hidden conversion, so every total can be checked.
  • Core logic in a package. A Swift 6 package with Swift Testing coverage.
